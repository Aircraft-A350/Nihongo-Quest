# 🌸 NIHONGO QUEST (日本語クエスト)

> **Cyberpunk-themed Japanese Learning Application**  
> Master Hiragana, Katakana, and Kanji with interactive quizzes, stroke order animations, and audio pronunciation.

## ⚡ Features

- **Gojuon Grid Explorer (Database Mode)**:
  - Complete Hiragana and Katakana charts with interactive audio and stroke animations.
  - Kanji database grouped by categories (Numbers, Time & Nature, People & Body, Verbs, Places & Things).
- **Interactive Stroke Order Animations**:
  - Vector-based stroke order visualization powered by KanjiVG.
  - Native Japanese Text-to-Speech (TTS) pronunciation.
- **Cyberpunk Training Arena**:
  - Real-time Romaji recognition with instant feedback.
  - Combo multiplier system (x1, x2, x5 XP bonuses).
  - Daily Streak & Leveling progression (Novice to Master).
  - Dynamic Sound Effects synthesized via Tone.js.
  - Filter training characters by consonant rows (A, K, S, T, N, H, M, Y, R, W, n).
- **Zero-Friction Offline & Cloud Persistence**:
  - Automatic local storage synchronization.
  - Optional Firebase Authentication & Firestore cloud sync.
  - Export & Import progress backup anytime.
- **Automated CI/CD**:
  - Continuous deployment to GitHub Pages via GitHub Actions upon push to `main`.

## 🛠️ Local Development

Simply open `index.html` in any modern web browser, or use a local HTTP server:

```bash
# Python 3
python -m http.server 8000

# or Node.js
npx serve .
```

Then navigate to `http://localhost:8000`.
